# ─────────────────────────────────────────────────────────────────────────────
# The layout-panel parity cases — declared ONCE, read by BOTH probes.
#
#   tools/winforms-ref/parity/panels-winforms/   → real WinForms   → panels-winforms.json
#   crates/kubuno-controls/examples/parity_panels.rs → the port    → panels-port.json
#   tools/winforms-ref/parity/compare-panels.ps1 → diffs the two
#
# Neither probe may carry a case of its own: if this file does not say it, it is
# not tested, and the two can therefore never drift apart in WHAT they test.
#
# Everything is in DIP at 96 DPI. The WinForms probe runs DPI-unaware with
# AutoScaleMode.None precisely so that one WinForms pixel is one DIP, which is
# the unit the port's Direct2D space already uses.
#
# GRAMMAR — whitespace separated, `#` starts a comment, blank lines ignored.
#
#   case <id> <flow|table|split|tab>
#   box   <w> <h> <padL> <padT> <padR> <padB> <none|single|fixed3d>
#
#   flow  <ltr|td|rtl|bu> <wrap:true|false>
#   child <w> <h> <mL> <mT> <mR> <mB> <flowbreak:true|false>
#
#   grid  <cols> <rows> <cellborder> <fixed|addrows|addcolumns>
#   col   <abs|pct|auto> <value>
#   row   <abs|pct|auto> <value>
#   cell  <w> <h> <mL> <mT> <mR> <mB> <col> <row> <cspan> <rspan> <fill|topleft>
#         (col/row = -1 means « no explicit cell »; `fill` docks the child so it
#          takes the whole cell, which is what the port's child_rects always does)
#
#   split <vertical|horizontal> <none|panel1|panel2> <distance> <splitterWidth>
#         <min1> <min2> <collapse1:true|false> <collapse2:true|false>
#   resize <w> <h>            (optional: re-measure after the container resizes)
#
#   tabs  <top|bottom|left|right> <multiline> <normal|filltoright|fixed>
#         <itemW> <itemH> <padX> <padY>
#   page  <caption>
# ─────────────────────────────────────────────────────────────────────────────
